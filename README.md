# SIBC CAFE ☕️

교회에서 쓰는 간단한 카페 주문 웹사이트입니다.
URL 하나로 여러 사람이 접속해서 주문하면, 관리자 페이지(`/admin`)에서 주문 내역을 한 번에
모아보고 영수증처럼 인쇄할 수 있습니다.

## 화면 구성

- `/` : 손님용 주문 페이지 (메뉴 선택 → 이름 입력 → 주문하기)
- `/admin` : 관리자용 페이지 (전체 주문 목록, 메뉴별 집계, 영수증 인쇄, 초기화)

## 기술 스택

- Next.js (App Router) + React
- Upstash Redis (Vercel 마켓플레이스에서 무료로 연결 가능한 저장소) — 주문 내역 저장용

## 1. 로컬에서 실행해보기

```bash
npm install
npm run dev
```

`http://localhost:3000` 에서 확인할 수 있어요. 단, 이 시점에는 아직 Redis가 연결되지
않았기 때문에 주문을 실제로 저장하려면 아래 2번 단계를 먼저 진행해야 합니다.
(화면 UI만 먼저 확인하는 건 바로 가능합니다.)

## 2. Vercel에 배포하고 Redis 연결하기

1. 이 리포지토리를 GitHub에 푸시합니다.
2. [vercel.com](https://vercel.com) 에서 New Project → 이 리포지토리를 선택해 배포합니다.
   (Next.js 프로젝트라 별도 설정 없이 바로 배포돼요.)
3. 배포된 프로젝트의 **Storage** 탭 → **Marketplace Database Integrations** 에서
   **Upstash Redis** (또는 KV로 표시될 수 있음) 를 선택해 연결합니다. 무료 티어로 충분합니다.
4. 연결하면 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` (또는
   `KV_REST_API_URL`, `KV_REST_API_TOKEN`) 환경변수가 프로젝트에 자동으로 추가됩니다.
   Settings → Environment Variables 에서 잘 들어갔는지 확인해주세요.
5. 다시 배포(Redeploy)하면 주문 저장이 정상적으로 작동합니다.

로컬에서도 Redis를 연결해 테스트하고 싶다면:

```bash
vercel env pull .env.local
```

명령으로 Vercel에 설정된 값을 그대로 받아올 수 있어요.

## 3. 관리자 페이지 비밀번호 설정 (선택)

`/admin` 페이지는 기본적으로는 비밀번호 없이 열립니다. 외부에 URL이 노출될 걱정이 있다면
Vercel 프로젝트 환경변수에 `ADMIN_PASSCODE` 값을 추가하세요 (원하는 문자열/숫자 아무거나).
설정하면 `/admin` 접속 시 비밀번호를 입력해야 주문 목록을 볼 수 있습니다.

## 4. 메뉴 수정하기

`lib/menu.js` 파일에서 메뉴 이름, 설명, 가격을 자유롭게 수정하거나 새 메뉴를
추가/삭제할 수 있습니다.

```js
{
  id: "americano",       // 고유 아이디 (영문, 중복되면 안 됨)
  name: "아메리카노",      // 화면에 보이는 이름
  desc: "설명 문구",
  price: 2000,           // 가격 (원)
}
```

## 5. 사용 흐름 예시

1. 교회에서 카페 운영 전, 관리자가 손님용 주문 페이지 URL을 공지합니다.
2. 여러 사람이 각자 휴대폰으로 접속해 메뉴를 고르고 이름을 입력해 주문합니다.
3. 관리자는 `/admin` 페이지에서 실시간으로 쌓이는 주문을 확인합니다.
4. 주문을 받는 시간이 끝나면 **영수증 출력** 버튼으로 전체 주문을 인쇄합니다.
5. 다음 번 주문을 새로 받기 전에 **초기화** 버튼으로 목록을 비웁니다.
   (초기화하면 이전 주문 내역은 사라지니, 영수증을 먼저 출력했는지 꼭 확인하세요.)

## 참고

- 결제 기능은 포함되어 있지 않습니다. (현장 결제/헌금함 등 별도 운영 방식 전제)
- 디자인은 스타벅스풍의 초록/크림 톤을 참고해 만들었으며, 실제 스타벅스 로고나
  상표는 사용하지 않았습니다.
